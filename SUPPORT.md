# Support

- **Bug?** Open a [bug report](https://github.com/rxova/react-inputs/issues/new?template=bug_report.yml).
- **Idea or usage question?** Start a
  [discussion](https://github.com/rxova/react-inputs/discussions).
- **Security issue?** Follow [SECURITY.md](./SECURITY.md) — please do not open a public issue.

When filing a bug, please say **which package** it concerns (`@rxova/react-intl-currency-input`,
`@rxova/react-rating-input`, or `@rxova/react-otp-input`) and include a minimal reproduction — the
prop combination you're using accounts for most reported behaviour differences.
