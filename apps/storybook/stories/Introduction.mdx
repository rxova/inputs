# rxova inputs

A suite of **headless, accessible React input components**. Each input ships as its own
package, unstyled by design: the components own behaviour, state, accessibility semantics
and form integration, while every pixel stays yours — styled via data attributes and CSS
custom-property tokens.

## Packages

| Package                                                                                              | What it is                                                                         |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| [`@rxova/react-otp-input`](https://www.npmjs.com/package/@rxova/react-otp-input)                     | One-time-code input: slots, grouping, WebOTP, paste handling, masking.             |
| [`@rxova/react-rating-input`](https://www.npmjs.com/package/@rxova/react-rating-input)               | Rating input: fractional fills, custom icons, native-radio semantics.              |
| [`@rxova/react-intl-currency-input`](https://www.npmjs.com/package/@rxova/react-intl-currency-input) | Locale-aware currency input built on `Intl.NumberFormat` — no locale data shipped. |
| [`@rxova/react-inputs`](https://www.npmjs.com/package/@rxova/react-inputs)                           | Meta-package re-exporting the whole suite from one entry point.                    |

```sh
npm install @rxova/react-otp-input
# or the whole suite
npm install @rxova/react-inputs
```

## Principles

- **Headless.** No stylesheet to fight. State is exposed through `data-*` attributes and
  render props; sizing and color through CSS custom properties.
- **Accessible.** Real form semantics — native inputs and radios under the hood, labels,
  `aria-invalid`, focus management. Every story here runs the a11y addon's checks.
- **Form-ready.** With a `name`, every input posts through native form submission, and the
  controlled API binds cleanly to React Hook Form, Formik, Final Form and TanStack Form.
- **Direction-aware.** Fill origin, caret movement and slot order honour `dir`. Use the
  **Direction** toolbar item above to flip every story into RTL.

## About this Storybook

Stories run against each package's **source** (the same aliasing convention as the
playground app), so prop tables are extracted from the annotated TypeScript source and the
workshop needs no prior library build. The stories double as living documentation of the
public API tiers: styled defaults, compound composition, render-prop escape hatches, and
the raw hooks.
